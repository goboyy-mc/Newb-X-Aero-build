# Newb X Aero

Newb X Aero is an enhanced vanilla RenderDragon shader for Minecraft Bedrock Edition, designed to preserve Minecraft's original charm while delivering a cleaner, more colorful, and cinematic visual experience.

Featuring vibrant blue skies, cinematic lighting, crystal aqua water, soft clouds, immersive atmospheric effects, and carefully balanced colors, Newb X Aero enhances the world without sacrificing the familiar vanilla aesthetic.

Built with performance in mind, it remains lightweight and suitable for both everyday gameplay and stunning cinematic screenshots.

# Installation

> **Disclaimer**
>
> Minecraft Bedrock Edition does not officially support RenderDragon shaders. Newb X Aero requires a compatible shader loader depending on your platform.

## Android

1. Install **[MB Loader](https://play.google.com/store/apps/details?id=io.github.bambosan.mbloader)**.
2. Launch Minecraft using **MB Loader**.
3. Import the **Newb X Aero** resource pack.
4. Enable it in **Settings → Global Resources**.
5. Restart Minecraft if the shader does not load immediately.

---

## Windows

1. Download and install **[BetterRenderDragon](https://github.com/QYCottage/BetterRenderDragon)**.
2. Follow the installation guide provided by BetterRenderDragon.
3. Import the **Newb X Aero** resource pack.
4. Enable it in **Settings → Global Resources**.
5. Restart Minecraft.

---

## Linux (x86_64)

> For **mcpelauncher-manifest** users only.

1. Install **[mcpelauncher-manifest](https://github.com/minecraft-linux/mcpelauncher-manifest)**.
2. Install **[mcpelauncher-materialbinloader](https://github.com/CrackedMatter/mcpelauncher-materialbinloader/releases)**.
3. Import the **Newb X Aero** resource pack.
4. Enable it in **Settings → Global Resources**.
5. Restart Minecraft if necessary.

---

## iOS

> A compatible RenderDragon-enabled Minecraft client is required.

1. Join the **[Newb Community Discord](https://discord.com/invite/newb-community-844591537430069279)**.
2. Follow the latest iOS installation guide or download links provided by the community.
3. Import the **Newb X Aero** resource pack.
4. Enable it in **Settings → Global Resources**.
5. Restart Minecraft if the shader is not applied.

# Configuration

Recommended graphics settings:

- Graphics: **Beautiful**
- Smooth Lighting: **On**
- Clouds: **On**
- Fancy Graphics: **On**
- Brightness: **50%–90%**

For better performance, use the **No Wave + No Fog** subpacks.

---

# Subpacks

## Default
The complete Newb X Aero experience with every visual feature enabled.

## Box Clouds
Replaces the default cloud shape with classic box-style clouds while maintaining a clean vanilla appearance.

## No Fog
Disables atmospheric fog for better visibility and slightly improved performance.

## No Wave
Turns off water wave animation to provide a calmer appearance and improve performance.

## No Wave + No Fog
Combines both optimizations for the best performance on lower-end devices.
